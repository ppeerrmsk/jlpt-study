## 原资料及已发现的排版问题

页码为 PDF 文件物理页，不一定等于纸面印刷页码。题面、选项、水印和解析均保持原版；页面提供明确当前题号和相应页码。

- 2010-07：答案表末组印为 70–70，但给出两个答案；题面有第 70、71 题，按原顺序对应这两题。
- 2013-07：第 1 题原资料选项序号重复；答题按钮按四个选项排列顺序对应。
- 2015-12：第 10 题原资料选项序号重复；答题按钮按四个选项排列顺序对应。

上述说明只列出整理过程中已发现的问题，不代表资料无其他错误。参考答案按随附表录入并交叉核对；未逐题进行日语教师语义审校。

## 范围

- 不含听力音频；听力题面和文字解析保存在完整 PDF 中，不纳入作答数。
- 初级语法汇总未作为 N1 真题收录，未复制进本包。
- 原有 89 道官方问题集和中文知识卡不变；新增题通过原 PDF 查看中文解析。
- 完整原文件名、SHA-256、题号、题型、材料页码与参考答案见 `data/provided-manifest.json`。
- 新题和旧题共用错题本与经验系统，已有记录无需重做。

## 重建

安装 Python 依赖 `pypdfium2`、`Pillow` 后，在工具目录运行：

```text
python scripts/build-provided-bank.py --input C:/你的资料目录/JLPT
node scripts/test.cjs
python scripts/package.py
```

重建脚本仅接受清单中哈希一致的原文件。新增其他资料需要另行整理题号和答案映射，不能直接更名覆盖原 PDF。
