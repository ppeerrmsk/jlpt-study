# 刷题工具：经验值成长版

状态：2026-10-19，单人学习与总体经验值版本；已扩充 N1 真题、关联中文知识库及两集官方 N2 笔试题。

- 独立便携目录，不改动原 SG 工具。全部资源随包携带，普通浏览器可打开 index.html 学习。
- 保留 89 道官方 2018 问题集原图、全选项、正答来源、知识卡、错题本、收藏与 JSON 题库导入。
- 首页以总体成长为主：总等级、累计 XP、升级进度、今日/本周 XP，以及跨 N1/N2 和导入题的每日 20 题任务。
- 各级别内置题库覆盖率与首次正确率独立展示，不将自添 JSON 题算入内置题库收录范围。
- XP 固定规则：初次作答 5，首次答对 15，每题首次隔日纠错 10，隔日温习 3（每天最多 20 题，同次纠错不叠加），20 道不同题打卡 30。
- 隔日奖励要求该题当天首次作答正确；当天先错后对不领取隔日奖励。首次答对仍可领取一次 15 XP。
- 每题隔日纠错只奖一次；之后可按隔日温习积累。所有初次与隔日奖励都基于稳定题目 ID，新增答题事件不能伪装成新的题目。
- 等级从 1 开始；升级需求 100 + 50 × (当前等级 - 1)。等级无固定上限，答错不扣 XP。
- XP 为答题事件的确定性派生数据。按时间与事件 ID 排序后计算，重复事件去重；备份中的 XP/等级字段不被信任。
- 记录格式为 jlpt-solo / version 2，兼容 jlpt-duo / version 1 个人学习记录。迁移保留档案、答案、笔记、收藏和导入题，丢弃连接及其他成员数据。
- 浏览器存储使用 jlpt-solo-v2；新记录不存在时只读旧 key 并迁移，不删除旧 key。损坏记录停止自动覆盖并支持原样导出。
- 本地保存与手动 JSON 迁移，无后台网络请求，无账号或共享服务依赖。资料与程序文件夹分开，移动或换机须备份。
- 错题规则仍为最后一次错误之后在两个不同日期答对才移出待复习，历史不删除。
- 交付包括单人 ZIP、中文使用说明、源代码、校验和与可重复核心验证。

## 2026-10-20 挑战玩法

- 三种固定长度短局：quick=5、combo=10、review=5；仅内置词汇和语法，按级别独立抽题，同局不重复，优先今天未做和首次练习的题。
- 每题只提交一次，得分为 100 + min(连续正确数 - 1, 5) × 20；答错 0 分并中断连击。全对 S，≥80% A，≥60% B，其余 C。最高分按级别及模式分开。
- 答题仍写入原 attempts；XP 规则和错题恢复规则不变。结算支持本局错题练习及对应知识卡。
- 每日 5 道不同题 / 8 道不同题答对 / 当天结算局覆盖 10 道不同题，分别 1/2/3 星标。8 个成就各奖励 2 星标。首次成就永久保留，隔日或后续答错不撤销。
- 星标派生自历史事件，可解锁墨蓝（8）和琥珀（20）配色；无消耗。没有外部字体、音频、服务或运行依赖。
- version 2 增加可选 game={version:1,runs,activeId,theme}。每局持久化 ID、模式、级别、开始时间、有序题目 ID 和提交事件 ID；不信任保存的得分、成就或星标。
- 校验局长度、唯一题号、级别题型、事件引用、题目对应、时间顺序和跨局事件唯一性。最多 10000 局。旧备份未带 game 时结构仍可原样往返。
- 同档案备份按局 ID 合并，较长的相同答案前缀覆盖较短快照；分叉或题目冲突拒绝导入。保留当前配色偏好，未完成局可继续。
- 本地保存按每次答案提交执行，刷新继续下一道未答题；完成局可从最近记录重新查看结算。降低动态效果偏好关闭计分动画。


## 2026-10-21 音效、动画与外观

- 增加 preferences-core.js（偏好校验、可读配色、反馈分类和音符序列）及 feedback.js（Web Audio 调度与短暂视觉反馈），无外部音效资源或网络依赖。
- 仅实际作答提交调用反馈；正确、3 连击及以上、升级三类反馈，升级优先。普通练习也有正确与升级反馈，连击沿用挑战计分。刷新或重新渲染不会重放。
- 音效默认开、35%，顶部和设置开关同步；音量为 0 不创建声音，静音立即停止已调度音符，异步恢复中的音频也会被取消。重复声音共用一个 AudioContext，失败不会阻断保存。
- 完整/轻量/关闭三档动画；系统减少动态效果优先。反馈浮层不拦截点击，最长 3 秒自动清理，导航及重试时清理；预览仅展示，不生成学习事件。
- version 2 增加可选 preferences 字段，旧备份未带该字段时原结构仍可往返。音量限定 0—100，色值只接受 #RRGGBB，枚举白名单，忽略额外字段。
- 自定义主题色/背景色，自动生成同明暗范围的卡片、正文、提示和按钮文字。正文、提示、强调文字对页面/卡片/柔和背景的对比度至少 4.5:1；按钮使用黑或白字。
- 通过统一 rem 字号和根字号切换标准/大/更大；密度和圆角独立配置。原题图不变。预设主题仍按成就解锁，自定义配色可直接使用。
- 完整备份包含偏好；导入含偏好的备份恢复其偏好和主题，导入旧备份保留当前偏好。恢复默认外观不清空学习数据或声音设置。
