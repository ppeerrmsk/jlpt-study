- N1、N2 与自添题共享经验和每日目标；等级阈值准确；内置覆盖率不混入自添题。
- 新备份往返、旧备份迁移、资料保留、连接凭据丢弃、忽略外部 XP/等级字段。
- 应用无联网请求、房间处理或同伴界面。

## 边界

- 自动化浏览器不允许 file:// 导航，因此实际浏览器验证使用本机 HTTP 预览；未声称完成直接双击文件的自动化实测。
- 工具仍由本地 HTML/CSS/普通脚本、图片与 PDF 组成，没有远程资源或 API 依赖。固定目录并定期导出备份，避免浏览器存储隔离或清理导致记录不可见。
- 没有听力音频，听力未接入作答；完整 PDF 中的听力文字材料仍保留。初级语法 PDF 未计入题库。
- 新增资料来自第三方整理版；未进行官方原卷认证或逐题教师审校。题面采用原图，文本提取仅辅助检索。
- 中文知识卡仍为原 89 张；新增解析在原 PDF 中。不同场次和官方问题集可能包含重复内容。
- XP 依据本机答题时间，是个人进度记录，不是防作弊考试系统。

打包脚本验证 ZIP CRC 与逐文件 SHA-256，排除服务、运行数据和测试备份。随包含源代码、来源映射、原 PDF、使用说明、校验清单，不包含任何学习者的答题档案。
