## N1 知识点

用户提供的 22 套 N1 笔试题中，550 道词汇、330 道句子语法与排序、108 道文章语法均建立逐题中文条目；加上原有 40 道官方题，共关联 1,028 道。

词汇条目保留考查词、读音（资料可用时）、中文意思及用法提示。语法条目整理接续、含义或当前语境；排序题、文章语法可回到完整原题查看上下文。相同级别、同一题型的同名词条归并为卡片，仍保留每道题的独立解释。

旧 PDF 的部分字体没有 Unicode 映射；整理时使用字形映射恢复文字，并对异常词条、中文摘要与字形作人工核对。原题图与原 PDF 是核对版面的依据。没有把无法识别的字形占位符作为正式知识点发布。结构与来源检查不等同于教师逐题审校，第三方资料仍可能存在未发现的问题。

卡片将“原资料解析摘录”和“用法与易混提示”分开标识。发现原资料明显错误时补充说明并链接原页，不修改原 PDF。已标注的例子包括：

- 2015-07 第 23 题、2016-12 第 3 题、2018-12 第 17 题：解析标题中的答案编号与参考答案表冲突，按题面核对并在卡片提示。
- 2018-07 第 26 题：区分「と引きかえに」的交换、代价与「にひきかえ」的对比。
- 2015-12 第 6 题：区分「励む」与「励ます」。
- 2021-07 第 40 题：原资料语法标签与本题「ために」不一致。
- 文章语法中另标注 2011-07 第 43 题选项编号重复、2013-07 第 41 题译文选项次序、2018-07 第 44 题译文否定表达等问题。

## 本次 N2 资料

来源为 [JLPT 官方问题集目录](https://www.jlpt.jp/cn/samples/sampleindex.html)：

- 2012 年《日本語能力試験公式問題集》：第 1—75 题，新增全部 75 道。
- 2018 年《日本語能力試験公式問題集 第二集》：保留原有第 1—49 题，新增第 50—75 题共 26 道。
- 每集 32 道词汇、22 道语法、21 道阅读；两集累计 150 道完整笔试题。

2012 与 2018 是问题集的出版年份。官方问题集收录过去实际出题的选编题，不能当作对应年份某一场完整考试卷。

新增词汇与语法题共 59 道，均有独立整理的中文解释；这些解释不是官方译文或官方中文解析。全部 14 张相关原题页均经视觉阅读，排序题还原整句并核对星号位置；文章语法结合全文语境整理。阅读题保留原文、图表和答案，未制作逐题中文解析。原 PDF 和答案表随包提供，答案第二页与跨页材料均已关联。

出典：日本語能力試験公式ウェブサイト（https://www.jlpt.jp/）。原文件、来源 URL 和 SHA-256 见 `data/official-download-manifest.json`。没有收集或打包听力音频。

## 复习方式与记录

答题反馈或错题本中的知识点按钮可直接进入知识卡。卡片显示“有关联错题待复习”，并优先展开刚进入的原题条目；点击“练习对应原题”可返回精确题号。可用中文、日文、读音或试卷筛选知识点。

知识卡的状态直接来自现有答题历史、收藏与错题规则；浏览不会增加 XP，也不会自动完成错题回顾。原有题目 ID、记录格式及经验规则保持不变。更新前导出完整 JSON 备份，换目录或换浏览器时恢复备份。

## 可维护数据

- `knowledge-provided.json`：880 条 N1 词汇、句子语法与排序条目。
- `knowledge-cloze.json`：108 条 N1 文章语法条目。
- `knowledge-n2.json`：59 条新增 N2 词汇、语法条目。
- `knowledge-editorial.json`、`knowledge-cloze-audit.json`、`knowledge-n2-audit.json`：编辑、来源与核对记录。
- `knowledge-bank.json` / `.js`：由上述条目加原有 89 条提示生成的运行时知识库。
- `official-additions.json`：新增 N2 题目与来源数据；`official-bank.json`：未改动的原有 89 道题基线。

维护已有条目后执行 `python scripts/build-knowledge-bank.py`，再运行 `node scripts/test.cjs`。新加题目应先接入题库，保留稳定题目 ID，再建立知识条目；构建器拒绝重复或不存在的题目关联。用户学习不需要安装 Python 或 Node.js。
