# 刷题工具

可离线使用的 JLPT N1 / N2 刷题工具。

## 开始使用

1. 在 [下载区](https://github.com/ppeerrmsk/jlpt-study/releases/latest) 下载精简便携包，并全部解压缩。
2. 打开 `jlpt-study` 文件夹，双击 `index.html`，使用 Edge 或 Chrome 打开。Windows 也可双击“开始学习.cmd”。
3. 在页面右上角选择 N1 或 N2，开始练习。

无需安装或登录。请保留整个文件夹，不要只复制 HTML 文件。从仓库下载或克隆后，也可以直接打开根目录的 `index.html`。

## 功能位置

| 侧边栏入口 | 功能 |
| --- | --- |
| 学习进度 | 今日打卡、正确率、题库覆盖率、经验值和等级 |
| 真题练习 | 按题型和场次筛选、作答、查看原题与答案、收藏 |
| 挑战与成就 | 快速局、连击局、错题挑战、每日任务和成就 |
| 错题与复习 | 待复习错题、历史错题和答题记录 |
| 词汇 · 语法 | 中文知识卡、对应真题和错题关联 |
| 成长记录 | 总体经验值与升级记录 |
| 设置与备份 | 音效、动画、颜色、文字大小和学习记录备份 |
| 试卷与来源 | 原 PDF、解析、参考答案及扩展题库导入 |

详细操作见 [使用说明](使用说明.txt)。

## 备份学习记录

记录保存在当前浏览器中。换电脑、移动文件夹、更换浏览器或清理浏览器数据前，在“设置与备份”中点击“导出完整备份”。在新环境打开工具后，通过“恢复学习备份”导入该文件。

复制程序或从 GitHub 下载，不会自动携带或同步个人学习记录。
